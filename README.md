# 🌍 Tourist Guide System

This is a simple **static website project** built with **HTML** and **CSS**. It serves as a basic tourist guide system to showcase popular travel destinations around the world.

**

## 🚀 How to Run the Project

1. Download or extract the folder.
2. Open the `index.html` file in any modern web browser.
3. Navigate through the site using the navigation bar.

---

## 📌 Features

- Clean and responsive design using plain HTML and CSS
- Showcases three famous tourist destinations:
  - Paris, France
  - Taj Mahal, India
  - Bali, Indonesia
- Simple contact form (non-functional for now)
- Easy to edit and customize

---

## 📷 Image Suggestions
